# Number Guessing Game (C)

A console-based Number Guessing Game developed in C.

## Features

- Random number generation
- Hint system
- Maximum attempts
- Input validation
- Beginner-friendly code

## Technologies Used

- C Programming
- GCC Compiler

## Concepts Covered

- Variables
- Loops
- if-else
- rand()
- srand()
- Macros
- break

## How to Compile

```bash
gcc main.c -o game
```

## Run

```bash
./game
```
